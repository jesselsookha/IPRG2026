# Introduction to Programming Logic  
**IPRG5111 · 2026**

Welcome to the official repository for **Introduction to Programming Logic (IPRG5111)**.

This repository serves as a **core learning resource** for the subject and will be used throughout the semester to complement the material covered in lectures and tutorials. You are encouraged to consult it regularly — not only to review content, but also to consolidate your understanding of programming logic as it develops over time.

Programming is not merely the memorisation of syntax. It is the practice of *thinking critically*, *structuring problems methodically*, and *expressing solutions with clarity*. This repository exists to support that intellectual process.

## ⟐ Course Overview

This subject introduces the foundational principles that underpin all programming languages. The emphasis is placed upon:

✦ Programming logic  
✦ Algorithmic thinking  
✦ Pseudocode  
✦ Flowchart design  
✦ Structured problem-solving  

The materials provided here reflect the pace and structure of the course. Files will be added, refined, and expanded as the semester progresses. Treat this repository as a **living reference**, not a static download.

## ⟐ Key Concepts Covered

✦ Fundamentals of pseudocode  
✦ Creation and interpretation of flowcharts  
✦ Sequential, decision, and iterative logic  
✦ Basic algorithm design  
✦ Introductory exposure to programming language syntax  
✦ Logical reasoning for problem-solving
