-- Case Structure

Now shift from logic to structure.

Use when:

- Comparing ONE variable against multiple specific values

- Basic structure 

	case of variable		// condition: if the variable = value  
		value: {instructions}
		value: {instructions}
		value: {instructions}
		value: {instructions}
		default: {instructions}
	endcase

- As discussed in class, the condition that is executed is `if variable = value`, and for our lessons, it is just that.

- cleaner than the many if..then statements.
- case is for equality checks — not ranges (in many languages). but it is noted that many modern programming languages have special case statements with features and functionality that really do offer more. (can research and read about the switch statement)

- A small note about 'default'

	* Default handles unexpected input
	* Never assume input will be valid.

	* What happens if user enters “9”?

- without 'default' - it is risky  	

	* Should we always handle unexpected values?
	* What happens in real systems when we don’t?

- There is no need for the default - if the user enters a value that is not allowed, the default white colour is attached to the user (the fltPrice). If the user enters a valid value (1, 2 or 3), then those associated prices are attached to the final price accordingly.

What if there was only 3 colour choices and nothing else?
If you enter the wrong value, we will repeatedly ask you until you provide the correct value.

* We use a do..while loop so that we force the program execution (the "user") to enter the loop at least once. 

If we are given the correct value, no error will be produced, and the correct colour price will be accumulated to the final price. The program will "exit" the loop because the condition will be false.

-- Menu-Driven Programs (Loop + Case)

This is where it becomes powerful.

Program runs:

1. Display menu
2. User selects option
3. CASE executes
4. Loop repeats

This is the foundation of:

* ATM systems
* POS systems
* Game menus

* Why do most systems use menus?
* Why combine loop + case?

- Example

2.	do 
		// Display Menu
		output "Enter Selection" 
		output "Play Game" 
		output "Load Saved Game" 
		output "Settings" 
		output "Exit"

		input strSelection // input the string value 

		case strSelection of 			
			"Play Game": playGame() 	// calling the procedures for each selection		
			"Load Saved Game": loadGame()
			"Settings":  settings()
		endcase
	while strSelection <> "Exit"
